# Jarvis AI

Jarvis is a personal AI assistant project built using:
- TypeScript
- Groq API
- Railway backend
- pnpm workspace architecture

## Current Features

- AI chat system
- Railway backend deployment
- Memory foundation
- Conversation handling
- Modular project structure

## Tech Stack

- TypeScript
- Node.js
- Express
- Groq API
- Railway
- pnpm

## Project Structure

```txt
artifacts/
lib/
scripts/
package.json
pnpm-workspace.yaml
```

## Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=
PORT=3000
NODE_ENV=production
```
